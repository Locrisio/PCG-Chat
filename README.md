# PCG-Chat
PCG Chat is a BETA messaging app for Windows. (Please don't confuse. PCG does not mean PSG, it's different), (My personal company is called PCG Studios, don't get confused).
This app contains features such as the message capsule, opening windows and others, you can add your own profile picture and ringtones and message tones, create groups and send emojis and files, put a personal message and a status and other functions, in addition to being able to use your ID.
